## Script (as written by Talha)

**HOOK**
I make my Claude call me "My king", not because I'm gay or I'm corny, but it actually tells me when my session is about to degrade.

**CONTEXT**
Developers like Peter Steinberger, the guy who made OpenClaw, use canaries. A canary is simply a sign to let the user know that something isn't behaving right.

**HOW**
So cracked developers like myself, we apply this in our Claude setup, and we do this by having Claude mention my name "My king" in every output.

**WHY IT WORKS**
This way, when a chat gets too long, Claude doesn't break all at once. It starts off by slowly leaving out one instruction at a time. And when that happens I can quickly catch it and start a fresh chat.
