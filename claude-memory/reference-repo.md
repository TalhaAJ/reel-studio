The reel-editing recipe (skill, styles, editor template, scripts, sounds, memory copy in `claude-memory/`, SETUP.md) lives in the private repo https://github.com/TalhaAJ/reel-studio (default branch `master`). The user has two PCs and wants only templates/skills synced, not raw footage or finished videos. After changing styles or skills, commit and push so the other PC can pull.
